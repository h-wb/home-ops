# Retired Open WebUI app

Paseo replaces the active app. These manifests and presets are reference only;
Flux does not reconcile this directory. The database, files, encryption key and
backups remain managed by `kubernetes/apps/main/llm/open-webui/ks.yaml`.

Restoration requires the app resources, LiteLLM grants and client gateway grants
together. Original definitions remain in Git history. Keep private conversation
history on private-approved backends after restoration.
